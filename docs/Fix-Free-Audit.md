## Path A — from the calendar page (your current screen)

### 1. Close or ignore Manage view
The right panel titled **Manage view** is only a filter. Leave it.

### 2. Look at the TOP of the main area (above the week grid)
You should see tabs / links like:
- Calendar view
- Appointment list view  
- **Calendar settings**

Click **Calendar settings**.

If you do not see those words, look for a **gear icon** near the top right of the calendar page, or a tab that says **Settings** next to the calendar title.

### 3. You should now see a LIST of calendars
Find the row named **Free audit** (it may still say Drafted).

### 4. Open it
Click the calendar name, **or** click the **⋯** (three dots) on that row → **Edit**.

### 5. Publish
Look for one of these:
- Draft / Drafted toggle → turn **OFF**
- Status → set to **Published** or **Active**
- Or a **Publish** button

Save / Continue.

### 6. Availability tab
Click **Availability** (or Office hours).

Set:
- Mon–Fri: **9:00 AM – 3:00 PM**
- Sat / Sun: **Off**
- Slot duration: **15 minutes**
- Timezone: **US/Eastern** or **America/New_York**

Save / Continue.

### 7. Confirmation / Notifications
Set alert / notification email to **shnippy1@gmail.com** (or assign the user that uses that email).

Complete / Save.

### 8. Copy the booking link
On the calendar list or edit screen, click **Share** / **Copy link**.

Test in a private window. It must NOT say 404.
